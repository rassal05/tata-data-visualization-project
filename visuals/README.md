# 📊 Tata Data Visualization Virtual Internship Project

## 🧠 Overview
This project was completed as part of the Tata Forage Data Visualization Virtual Internship.

The objective was to analyze online retail transaction data and generate business insights for executive stakeholders using Power BI.

---

## 🧹 Data Cleaning
Before analysis, the dataset was cleaned by:
- Removing records where Quantity < 1
- Removing records where UnitPrice < 0
- Handling missing values
- Creating Revenue calculations

---

## 📈 Business Questions Solved

### 1. Monthly Revenue Trends in 2011
- Used line chart
- Identified strong seasonal spike in November

### 2. Top 10 Revenue-Generating Countries (Excluding UK)
- Used stacked bar chart
- Found Netherlands, Germany, and France as key markets

### 3. Top 10 Customers by Revenue
- Identified high-value customers for retention strategies

### 4. Product Demand by Country
- Used map visualization to identify expansion opportunities
